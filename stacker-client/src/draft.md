# Роутер для клиентской стороны
## Плюсы
 - не нужно разворачивать специальный сервер
 - не нужна сессия на серверной стороне
 - возможность иметь бесконечную сессию на клиенте
 - меньше вероятность попасть на таймаут

## Минусы
- увеличение траффика на стороне клиента
- вероятно необходимость шифрования данных стека на стороне компонентов
- вероятно необходимость шифрования настроек в конфиге или организация их отдельного хранения (необходимость сервера, который будет пропускать через себя траффик и обогащать его настройками исполнителей)

## Как работает

1. загружаем конфигурацию 
2. создаём стек
3. вызываем mainFlow
4. получаем и обрабатываем вопрос
5. после того как клиент сформирует ответ отправляем ответ обратно
6. при получении команды OPEN резолвим и вызываем требуемый Flow, увеличиваем стек
7. при получении команды RETURN уменьшаем стек, передаём данные в Flow из верхнего элемента стека
